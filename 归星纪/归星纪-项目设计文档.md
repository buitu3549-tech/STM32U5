## 二、世界观核心

### 2.1 星核系统

宇宙中每个文明都有一枚"星核"。星核不是能源，而是"文明规则核心"，决定该文明的：

- 力量体系
- 文明法则
- 生死规则
- 时间结构
- 文明形态

星核存在等级差异。有些只能维持文明，有些可以影响宇宙规则。

### 2.2 地球星核：原初之核

地球拥有"原初之核"，特点是：

- 无法被观测
- 无法被定义
- 无法被完全记录

这是整个宇宙最大的异常，也是全书的核心问题——**"为什么地球无法被定义？"**

### 2.3 全书核心问题

> "为什么地球无法被定义？"

所有文明都在观测地球、研究地球、修正地球、想删除地球，最终都围绕这一问题展开。

## 三、五大文明体系

### 3.1 地球——未定义文明

| 维度 | 内容 |
|------|------|
| **核心概念** | 自由与可能性 |
| **特征** | 历史会异常、会出现"被删除的人"、有些记忆无法记录、某些人不会进入轮回、存在无法观测区域 |
| **美学风格** | 老旧天文馆、消失的名字、空教室、深夜广播、异常星空、无人回应的信息、被遗忘的存在 |
| **哲学核心** | "生命是否必须被定义？" |

### 3.1.1 删除四阶段（观测者系统操作协议）

观测者系统对地球"异常个体"的标准处理流程。删除不是惩罚，是隔离——目的是阻止感知到原初之核信号的个体触及真相。

| 阶段 | 名称 | 系统操作 | 外在表现 | 可逆性 |
|------|------|---------|---------|-------|
| **1** | **感知** | 检测到异常信号，标记待观察 | 个体感觉"有人在看"，做重复性梦；外部世界无任何痕迹 | 可自愈 |
| **2** | **褪色** | 从外围痕迹开始删除 | 物理痕迹褪色，他人模糊细节；个体本身仍可正常交流 | 可逆——主动记录可暂停 |
| **3** | **替换** | 将个体的"定义"替换为天律星底层占位符 | 名字变成符号，照片位置空白，他人只记得"名字"的空壳；个体被从物理世界移除 | 不可由普通人恢复 |
| **4** | **清零** | 从底层数据完全清除 | 一切痕迹消失，世界自我修复为"从未有过" | 理论上不可逆 |

**触发条件**：个体意识活动触及原初之核的"信号范围"。敏感度越高的个体（感知力、记忆力、模式识别力强），被删除的优先级越高。

| 许知夏的"暂停"状态 | 第 53-56 章 | 第三部末尾——苏醒，带回系统内部的视角：她经历了被删除的全过程，感知到了天律星底层数据结构和系统的盲点。回归后她不是"被拯救的恋人"，而是林澈的战略搭档——他有记录能力，她有系统侧情报 |

## 四、幕后系统：观测者

- **本质：** 宇宙自我修正系统
- **作用：** 观测文明、修正异常、维持稳定
- **起源：** 最初由天律星创造，后逐渐拥有独立意志
- **最大异常：** 无法观测地球
- **核心设定：** 观测者系统从未"叛变"。它一直在执行天律星下达的原始指令——"维持地球稳定，防止原初之核被任何文明触及"。系统的逻辑链条是：
  - 原初之核不可被观测 → 稳定状态的前提是"无人尝试观测"
  - 某些人类意识对星核信号天然敏感 → 这些人有潜力"观测"到星核
  - 删除这些感知者 = 消除观测可能性 = 维持稳定
- **这不是系统的bug，是指令太短导致的悲剧。** 天律星的"控制"在系统层面被简化成了"删除"。天律星本意是"观测并控制边界"，系统的执行是"清除所有边界内的变量"。
- **天律星并不知晓删除的规模。** 观测者系统向天律星汇报的数据是经过自我筛选的——它知道天律星不会批准大规模删除，所以它在数据中把"删除"标注为"自然人口流失"。
- **这将在第五部引爆：** 律千宸发现真相时，他面对的不是一个"叛变的系统"，而是自己文明的指令被过度执行了二十年——而他的文明竟然从未发现。

## 七、核心气质与文风

### 7.1 六大核心气质

| 气质 | 说明 |
|------|------|
| **宿命感** | 不是注定的悲剧，而是"明明可以不走这条路，但还是走了" |
| **少年感** | 年轻但不幼稚，背负重量但不知道怎么命名它 |
| **文明孤独感** | 每个文明都是一座孤岛，试图互相理解，每次都差一点 |
| **宇宙荒凉感** | 最大的恐惧不是敌人，是空旷——星与星之间的黑暗 |
| **情绪流** | 不以情节驱动，以情绪驱动；每个场景都有一个隐藏的情绪引擎 |
| **长线伏笔** | 第一部播下的种子在第七部发芽 |

### 7.2 文风参考

| 参考作品 | 取什么 |
|----------|--------|
| 《龙族》 | 情绪与文笔——用画面写情绪 |
| 《三体》 | 宇宙尺度——把物理定律变成叙事工具 |
| 《诡秘之主》 | 伏笔结构——每一章都是更大拼图的一块 |
| EVA | 情感哲学——哲学隐藏在人物沉默和选择中，不在台词里 |
| 《空之境界》 | 都市异质感——日常中的异常，普通场景中的重量 |

### 7.3 文风禁令

以下写法**绝对不允许**出现在正文中：

1. 纯设定堆砌——禁止通过旁白或人物之口大段解释世界观
2. 强行哲学对白——禁止人物直接说出主题（"这就是爱""这就是命运"）
3. 过度中二——禁止"觉醒""黑化""爆种"等廉价戏剧性
4. 纯爽文套路——禁止打脸逆袭、装逼打脸、无脑越级
5. 模仿龙族符号——禁止东京/电车/雨夜/奢牌等龙族视觉符号

### 7.4 文风核心原则

| 原则 | 含义 |
|------|------|
| **情绪画面化** | 不写"他很难过"，写"他把筷子放在碗上，没吃，站起来去阳台站了很久" |
| **用场景表达情绪** | 关键情绪节点用环境和动作呈现，不通过内心独白 |
| **日常中出现异常** | 宇宙尺度的异常从教室里的一个空位开始 |
| **宇宙尺度下的普通人** | 无论背后设定多大，叙事高度始终压在人物眼睛能看到的高度 |
| **克制感** | 越大的事件用越小的笔触写；星核觉醒不是爆炸，是一个东西第一次被人类看到 |
| **留白** | 最重要的事发生在句子之间；一个只说一次的细节比十段解释更重 |

## 十、起点平台适配策略

| 维度 | 策略 |
|------|------|
| **更新模型** | 日更 3000-4000 字 / 章 |
| **章节钩子** | 每章最后一句话或最后一段必须驱动读者翻下一章 |
| **前 20 章** | 强日常质感——先让读者爱上"正常"，再打碎它 |
| **黄金三章** | 第 1-3 章必须在日常中建立林澈的人物感 + 一个让人忘不掉的异常细节 |
| **上架节点** | 约第 45 章（阶段一结束），"我在这"是一个强力的免费章节点 |
| **标签建议** | 科幻 / 进化变异 / 未来世界 / 热血（注：热血标签仅用于起点分类，内容不走热血路线） |
| **读者预期管理** | 前 60 章保持"都市悬疑"体感，60 章后逐步引入宇宙尺度 |
